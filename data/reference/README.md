# note スキ率参考データ

このディレクトリは、View/Like 比（スキ率）の推定根拠として、note.com 上に公開された
事例を整理した参照データです。Perplexity による事前リサーチで収集されました。

## ファイル

- `note_like_rate_cases.csv` — 個別事例 (n=26)。投稿ごと/アカウントごとのビュー・スキ・スキ率を含みます。
- `note_like_rate_summary.json` — 上記から計算した集計（記事タイプ別 / ジャンル別 / 上位下位ケース）。

## 集計結果（実測対象 n=15）

| 指標 | 値 |
|---|---|
| 平均スキ率 | 14.05% |
| 中央値 | 13.70% |
| 加重平均 | 13.58% |
| レンジ | 0.09% – 25.45% |
| 10%以上の比率 | 80.0% |

## View/Like 比の換算

`スキ率 = スキ数 ÷ ビュー数 × 100` の逆数として、

- スキ率 25% → 約 4 倍
- スキ率 10% → 10 倍
- スキ率 5%  → 20 倍
- スキ率 3%  → 約 33 倍
- スキ率 1%  → 100 倍

## 重要な注意点

- **note公式は平均的な View/Like 比を公表していません。**
- 上記サンプルは **クリエイター本人が公開したデータ** に限られ、エンゲージメントが高い
  運用者に偏っている可能性があります。プラットフォーム全体の中央値はこれより低く出る
  と推定されます。
- 検索流入主体の記事ではスキ率が 1% 前後まで下がる例があり、その場合 100 倍を超えます。
- noteの「全体ビュー」は記事ページ閲覧だけでなくタイムライン等の一覧表示も含むため、
  通常の PV とは異なります。

## 実装での扱い

`note_analyzer.py` および `dashboard/lib/note-api.ts` では、これらを根拠に

- `estimated_views_low`  = `likes × 10` (高スキ率寄り)
- `estimated_views`      = `likes × 20` (中央推定)
- `estimated_views_high` = `likes × 33` (低スキ率寄り)

の 3 列を出力していますが、これは **公開実例から逆算した参考レンジの一例** であり、
統計的な標準値ではありません。記事タイプや流入経路で大きく変動します。
